# Changelog

## 0.1.0 — 2026-09-17 (unverified Unreal implementation)

- Bootstrap UE5.6 C++ project and Win64 targets.
- Closed Przebudzenie environment generated at runtime: apartment, stairs, courtyard, street, alley, shelter.
- Third-person input, interaction interface, inventory, linked puzzles and 13 mission objectives.
- One pursuer with perception, navigation, combat and search/return states.
- Four progression checkpoints plus a new-game checkpoint, save validation, death/reload and minimal keyboard UI.
- Procedural placeholder source assets, Lumen/PBR configuration and Windows packaging scripts.
- Engine-independent production-state and asset tests; manual Windows acceptance gates remain open.

Diffuse, DirectX normal and ARM (AO/Roughness/Metallic), 2048², physical tile 2 m.
Original URLs, provider MD5, independently computed SHA-256 and file lengths
are locked in Data/city_asset_acquisition.json. Files are versioned for offline
reproducibility. This workflow downloads no scripts, archives or paid models.
Live API was used only to research/select metadata; downloader uses pinned files
and prints this credit. The game does not contact the API.

Original tenement kit: WroclawTheGame project procedural authoring. Geometry
and fallback textures are project-owned; viewing-only municipality photo
references are recorded in its PROVENANCE.json. Existing third-party models
remain credited in docs/FREE_MODEL_ASSETS.md and source catalogs.

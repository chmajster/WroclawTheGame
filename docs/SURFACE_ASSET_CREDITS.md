# Surface assets — Poly Haven

This project uses PBR textures from **Poly Haven**, licensed under
[CC0 1.0](https://polyhaven.com/license). Original asset authors:

| Profile | Asset | Authors |
|---|---|---|
| Asphalt | [Asphalt 02](https://polyhaven.com/a/asphalt_02) | Rob Tuytel |
| Brick | [Brick Wall 001](https://polyhaven.com/a/brick_wall_001) | Rob Tuytel, Dimitrios Savva |
| Plaster | [Plastered Wall 02](https://polyhaven.com/a/plastered_wall_02) | Charlotte Baglioni |
| Concrete | [Concrete Floor 02](https://polyhaven.com/a/concrete_floor_02) | Rob Tuytel |
| Cobble | [Cobblestone Floor 03](https://polyhaven.com/a/cobblestone_floor_03) | Rob Tuytel |
| Wood | [Wood Floor](https://polyhaven.com/a/wood_floor) | Dimitrios Savva |

Imported maps: Diffuse (sRGB), DirectX Normal and ARM (linear), 2K PNG.
`Data/surface_sources.json` records each original URL, provider MD5, local SHA-256,
physical dimensions, legacy scale label and author roles. The numeric dimensions
field (mm) is used for cm-based tiling; some legacy scale labels disagree and are
retained for audit. Final brick/stone module dimensions still need visual site-reference QA.

`Scripts/fetch_surface_sources.py` is an explicit authoring tool using the public
[Poly Haven API](https://polyhaven.com/our-api). No API calls occur in the game or
ordinary build. It downloads only the six named sets, verifies checksums and rejects
unexpected hosts, oversized responses and incomplete files. Source images are cached
under `Saved/SurfaceSource/PolyHaven`; imported assets are included in Content.

Other textures generated by `make_surface_assets.py`, shader code and procedural decal
masks are original project work, not Poly Haven scans. No claim is made that these
generic materials depict a specific surveyed building in Wrocław.

# City seasons

The seasonal state exposes foliage, daylight, crowd and wetness biases plus whether snow is allowed. Values are gameplay/art-direction parameters, not a weather forecast.

4. NPC clothing/crowd/activity variants;
5. seasonal decorations as separate Data Layer;
6. persist season/date in save and define campaign calendar;
7. visual/performance QA for each season.
